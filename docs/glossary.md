# Glossary

[Українською](glossary.uk.md)

| Term | Meaning | Where |
|---|---|---|
| World | One saved world: seed, event log, the world's key | `core.rs`, `storage.ts` |
| Seed | The number from which everything random in the world follows deterministically | `rng.rs` |
| Event log | Everything that happened through the player: `Event::Input` and its outcomes, signed by a chain | `event.rs` |
| Snapshot | A MAC-verified state for opening fast: snapshot + the tail of the log | `state.rs::Snapshot` |
| Core | The deterministic Rust that decides everything | `crates/teul-core` |
| Shell / client | The TypeScript that asks the core and draws | `app/src` |
| Content pack | `content/base/pack.json`, generated by scripts | `scripts/` |
| Map | A large outdoor location made of cells | `world_maps.py::Map` |
| Interior | A room behind a building's door | `interiors.py::Inside` |
| Site | A building or a plot on a map: door, footprint, jobs | `Map.site` |
| Landmark | A named rectangle on a map (`square`, `park`, `door:<site>`) | `town_growth.py::landmark` |
| Prop | An item standing on a map | `LocationProp` |
| Town flag | A state of the town for the day (`full_moon`, `offerings`, `storm`, `grow:…`) that shows or hides props and stations | `town.rs::town_flags` |
| Station | An action at a prop: buy, sell, make, gather, play, make a wish… | `economy.rs`, `StationDef` |
| Help | A one-time task for a resident that opens the way (a key, a place) | `HelpDef` |
| Guide / key | A thing on the keyring that opens a place: a lantern, the cellar key, a pass, a driving licence | `ItemDef.key` |
| Pocket | What one carries: 8 places + a bag | `economy.rs` |
| Chest | Things at home, not in the pocket | `Stash`/`Take` |
| Story (quest) | People's requests with stages and thanks at the end | `quests.rs` |
| The day's small need | A daily request drawn from the day | `quests.rs`, `job` |
| Shift | Work at a place in town during its hours | `work.rs` |
| Skill | A know-how that grows by doing; levels in words | `skills.rs` |
| Warmth (toward the player) | From "stranger" to "dear" | `feelings.rs::Warmth` |
| Mood | How a resident feels at this moment | `feelings.rs::Mood` |
| Comfort (warmth) | How warm the hero feels, from −3 to +3, shown only by effects | `warmth.rs::comfort_view` |
| Great holiday | A holiday with preparation, the day itself and the clean-up | `festival.rs::BIG` |
| Quiet date | A church or state holiday without town decorations | `holidays.rs` (`festive: false`) |
| Rift | A crack into another world at an equinox or a solstice | `holidays.rs`, `sky.rs`, `rift.py` |
| Lypove inside out (Липове навиворіт) | The winter rift world: the same town, with creatures | `rift_winter` |
| Full moon | The night of the full moon: a fire and a circle at the old shrine | `holidays::full_moon` |
| Old shrine (капище) / the Old Circle | An idol, stones and a fire in the forest | `faiths_world.py` |
| Offerings | Bowls of gifts in the temple on its days; the station "Leave an offering" | `faiths.py` |
| Eerie night | Optional horrors on certain nights | `horror.ts`, `wonders/nightmare.ts` |
| Coupon | Five holes for offences on the road | `drive.rs` |
| Story provider | A function that gives the paper the day's stories | `paper.rs::providers` |
| Missed issues | Papers lying by the door after days away | `away.ts` |
| Retired | An event, command or item of version 1.x that the game no longer has: a save holding it opens, and it is passed over | `event.rs::RETIRED_EVENTS`, `pack.json` `retired` |
| Ghost hero | The hero's silhouette through whatever stands in front | `scene.ts::heroGhost` |
