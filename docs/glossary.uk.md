# Словник

[English](glossary.md)

| Термін | Що означає | Де |
|---|---|---|
| Світ | Один збережений світ: зерно, журнал подій, ключ світу | `core.rs`, `storage.ts` |
| Зерно (seed) | Число, з якого детерміновано виходить усе випадкове у світі | `rng.rs` |
| Журнал подій | Усе, що сталося через гравця: `Event::Input` і наслідки, підписані ланцюгом | `event.rs` |
| Знімок | Перевірений MAC-ом стан, щоб відкривати швидко: знімок + хвіст журналу | `state.rs::Snapshot` |
| Ядро | Детермінований Rust, що вирішує все | `crates/teul-core` |
| Оболонка / клієнт | TypeScript, що питає ядро й малює | `app/src` |
| Пакет вмісту | `content/base/pack.json`, згенерований скриптами | `scripts/` |
| Мапа | Велика локація надворі з клітинок | `world_maps.py::Map` |
| Приміщення | Кімната за дверима будівлі | `interiors.py::Inside` |
| Сайт | Будівля чи майданчик на мапі: двері, площа, роботи | `Map.site` |
| Орієнтир | Іменований прямокутник на мапі (`square`, `park`, `door:<site>`) | `town_growth.py::landmark` |
| Проп | Предмет, що стоїть на мапі | `LocationProp` |
| Прапорець міста | Стан міста на день (`full_moon`, `offerings`, `storm`, `grow:…`), що показує чи ховає пропи й станції | `town.rs::town_flags` |
| Станція | Дія біля пропа: купити, продати, зробити, зібрати, пограти, загадати… | `economy.rs`, `StationDef` |
| Допомога | Одноразова справа для мешканця, що відкриває шлях (ключ, місце) | `HelpDef` |
| Провідник / ключ | Річ на зв'язці, що відкриває місце: ліхтар, ключ від льоху, перепустка, права | `ItemDef.key` |
| Кишеня | Речі, що носиш із собою: 8 місць + торба | `economy.rs` |
| Скриня | Речі вдома, не в кишені | `Stash`/`Take` |
| Історія (квест) | Прохання людей з етапами й подякою наприкінці | `quests.rs` |
| Дрібна потреба дня | Щоденне прохання, витягнуте з дня | `quests.rs`, `job` |
| Зміна | Робота на місці містечка в його години | `work.rs` |
| Навичка | Уміння, що росте від справи; рівні словами | `skills.rs` |
| Тепло (до гравця) | Від «незнайомий» до «рідний» | `feelings.rs::Warmth` |
| Настрій | Як почувається мешканець цієї миті | `feelings.rs::Mood` |
| Відчуття (тепла) | Як тепло героєві, від −3 до +3, видно лише ефектами | `warmth.rs::comfort_view` |
| Велике свято | Свято з підготовкою, днем і прибиранням | `festival.rs::BIG` |
| Тиха дата | Церковне чи державне свято без міських прикрас | `holidays.rs` (`festive: false`) |
| Розлом | Тріщина в інший світ на рівнодення чи сонцестояння | `holidays.rs`, `sky.rs`, `rift.py` |
| Липове навиворіт | Зимовий світ розлому: те саме місто з істотами | `rift_winter` |
| Повня | Ніч повного місяця: вогонь і коло на капищі | `holidays::full_moon` |
| Капище / Старе коло | Ідол, камені й вогнище в лісі | `faiths_world.py` |
| Підношення | Миски з дарами в храмі на свої дні; станція «Залишити підношення» | `faiths.py` |
| Моторошна ніч | Опційні жахи в певні ночі | `horror.ts`, `wonders/nightmare.ts` |
| Талон | П'ять дірок за порушення на дорозі | `drive.rs` |
| Провайдер сюжетів | Функція, що дає газеті сюжети дня | `paper.rs::providers` |
| Пропущені випуски | Газети, що лежать біля дверей після днів відсутності | `away.ts` |
| Вилучене (retired) | Подія, команда чи річ версії 1.x, якої гра більше не має: збереження з нею відкривається, а її саму пропущено | `event.rs::RETIRED_EVENTS`, `pack.json` `retired` |
| Напівпрозорий герой | Силует героя крізь те, що стоїть попереду | `scene.ts::heroGhost` |
